# DevOps Git Workflow Project

## Objective
To demonstrate Git version control and GitHub collaboration workflows.

## Tools Used
- Git
- GitHub
- Markdown

## Project Structure
- README.md – Project overview
- .gitignore – Files excluded from version control
- docs/ – Git workflow documentation
- scripts/ – DevOps utility scripts

## Branching Strategy
- main – Stable project version
- dev – Development integration
- feature – New feature development

## Workflow
1. Create and manage branches.
2. Commit changes with meaningful messages.
3. Create Pull Requests.
4. Review and merge changes.
5. Create a Git version tag.

## Learning Outcomes
- Git fundamentals
- Branching and merging
- Pull Requests
- Conflict resolution
- Git tags and .gitignore
